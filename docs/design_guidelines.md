# Design Guidelines

**Стиль:** Корпоративный минимализм, высокая плотность данных.
**Библиотека:** `shadcn/ui` + `Tailwind CSS`.

## Цвета (Slate & Blue)
* **Primary:** `bg-slate-900` (текст), `bg-blue-600` (активные кнопки).
* **Background:** `bg-slate-50` (общий фон), `bg-white` (карточки).
* **Border:** `border-slate-200`.

## Типографика
* Font: `Inter` (sans-serif).
* Размеры: `text-sm` — базовый размер для интерфейса (компактность).

## Компоненты
* **Buttons:** `h-9 px-4 py-2` (Small/Medium).
* **Inputs:** Стандартные из shadcn. Обязательна валидация (красная рамка при ошибке).
* **Cards:** Используем для группировки (Заявитель, Звонок, Поиск).
* **Toasts:** Используем `Sonner` (входит в shadcn) для уведомлений ("Звонок сохранен").

## Layout (Grid)
* Экран оператора разделен на 2 зоны:
    * **Left (40%):** Форма ввода.
    * **Right (60%):** Результаты поиска и база знаний.
