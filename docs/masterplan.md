# Masterplan: Support Operator Panel

## 1. Обзор и Цели
**Проект:** Веб-приложение для операторов контакт-центра.
**Цель:** Заменить Excel-формы на современный веб-интерфейс, ускорить обработку звонка за счет AI-поиска и обеспечить прозрачную аналитику для руководства.
**Философия:** "Скорость для оператора, данные для бизнеса, современный DX для разработчика".

## 2. Ключевой функционал
1.  **Рабочее место (Single View):** Единый экран ввода данных с интегрированным поиском.
2.  **AI Search:** Мгновенный поиск по базе знаний (интеграция с `assist-craft-qna`).
3.  **Knowledge Loop:** Возможность операторам предлагать новые ответы -> Модерация админом.
4.  **Аналитика:** Дашборд руководителя в реальном времени.

## 3. Технический стек (Modern 2026)
* **Repo:** Monorepo (`support_operator_panel`).
* **Backend:** Python 3.12+, **FastAPI**, **uv** (package manager), **Ruff** (linter), SQLAlchemy (Async), Pydantic v2.
* **Frontend:** React 18+, TypeScript, **Vite**, **pnpm**, **TanStack Query** (state/cache), **Zustand**, **shadcn/ui** + Tailwind CSS.
* **Database:** PostgreSQL 16+.
* **Infrastructure:** Docker Compose (Local), GitHub Actions (CI/CD), Nginx (Prod).

## 4. Модель данных (High Level)
* `Users`: Операторы и Админы.
* `Calls`: Лог звонков (кто, откуда, тема, длительность).
* `Dictionaries`: Регионы, Отделы (синхронизируются админом).
* `KnowledgeBase`: (Внешняя система, локально храним только черновики/предложения).

## 5. Стратегия разработки
Используем подход **"Walking Skeleton"**:
1.  Настройка среды (Docker, UV, PNPM).
2.  Сквозной канал (БД -> Бэк -> Фронт).
3.  Наращивание функционала (Форма -> Поиск -> Дашборд).
